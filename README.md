# 2. How do I approach developing programs?

* What new development strategies did you use while working on your 3D scene?

    For the development of the 3D scene, I utilized older strategies of development, while also incorporating newer tactics.
Since a lot of these were newer topics, I spent a lot of time reading material and trying to implement it into my code. If at 
first I did not succeed, I would take a step back, reread my code and figure out what went wrong. If could not figure it out, I would go
back through the material to see if it would help me identify the error. If I still had trouble, I would revert back to my last successful build 
and rewrite the code from scratch and try it differently. 

* How did iteration factor into your development?

    The development of this project occurred throughout the course of six weeks, where we slowly added onto it each week. Doing this
is a prime example of iteration in development. I would focus on one aspect of the project until I had it successfully implemented 
and then would work on the next step the following week. 

* How has your approach to developing code evolved throughout the milestones, which led you to the project’s completion?

    Early into this project, my code was a bit unorganized and not properly commented, but as the weeks progressed, I got better
  at organizing it and commenting my additions. Making it so that if anyone else needed to review or make changes, they would be able to navigate
  the code and know exactly what my  thought process was, at the time of writing it.
